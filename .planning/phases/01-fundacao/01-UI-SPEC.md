# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (initialize before implementing) |
| Preset | none — run `npx shadcn@latest init` with dark mode default |
| Component library | Radix UI (via shadcn) |
| Icon library | lucide-react (ships with shadcn) |
| Font | Cinzel (headings/display — tribal/gaming feel) + Inter (body — legibility) via Google Fonts |

**shadcn components required for Phase 1:**
`button`, `card`, `badge`, `input`, `sheet`, `command`, `separator`, `navigation-menu`

**Initialize command:**
```bash
npx shadcn@latest init
npx shadcn@latest add button card badge input sheet command separator navigation-menu
```

Default theme mode: **dark** (enforced via `next-themes` with `defaultTheme="dark"` and `disableTransitionOnChange`).

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge padding |
| sm | 8px | Button internal padding (vertical), list item gaps |
| md | 16px | Default element spacing, card padding, input padding |
| lg | 24px | Section padding, sidebar item groups |
| xl | 32px | Layout gaps between major UI zones |
| 2xl | 48px | Major section breaks (hero to cards, cards to footer) |
| 3xl | 64px | Page-level top/bottom padding for hero section |

Exceptions:
- Topbar height: 56px (not on scale — matches shadcn navigation-menu height convention)
- Sidebar width: 240px on desktop, full sheet width on mobile
- Touch targets: minimum 44px height for all interactive elements (accessibility requirement)

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 16px | 400 (regular) | 1.5 | Inter | Paragraphs, descriptions, sidebar items |
| Label | 14px | 400 (regular) | 1.4 | Inter | Form labels, nav links, badges, meta text — distinguished from Body by size (14px) and color (`--muted-foreground`) |
| Heading | 24px | 700 (bold) | 1.2 | Cinzel | Section headings (category titles, card headings) |
| Display | 40px | 700 (bold) | 1.1 | Cinzel | Hero title (site name overlay on hero banner) |

**Weights used:** 400 (regular) and 700 (bold) only.
- 400 applies to all Inter text (Body and Label roles).
- 700 applies to all Cinzel text (Heading and Display roles).
- Label is distinguished from Body through size (14px vs 16px) and color (`--muted-foreground` vs `--foreground`), not weight.

**Note on Cinzel:** Load only weight 700. Use `font-display: swap`. Fallback stack: `Georgia, serif`.

## Color

All values are Tailwind v4 CSS custom properties declared in `src/app/globals.css`. Dark mode is the only mode for this site.

| Role | CSS Variable | Hex Reference | Usage |
|------|-------------|---------------|-------|
| Dominant (60%) | `--background` | `#0a0a0a` (near-black) | Page background, base surface |
| Secondary (30%) | `--card` | `#141414` (dark gray) | Cards, sidebar background, topbar background, footer |
| Accent (10%) | `--primary` | `#c9973a` (gold/amber) | See reserved list below |
| Accent hover | `--primary-hover` | `#e0b04e` (lighter gold) | Hover state for accent elements only |
| Destructive | `--destructive` | `#dc2626` (red-600) | Destructive actions only — no other use |
| Muted text | `--muted-foreground` | `#6b7280` (gray-500) | Secondary text, placeholders, disabled states |
| Border | `--border` | `#262626` (gray-900) | Dividers, card borders, input borders |
| Foreground | `--foreground` | `#f5f0e8` (warm white) | Primary text — warm tint to match tribal aesthetic |

**Accent (`#c9973a`) reserved for:**
- Site logo / wordmark
- Primary CTA buttons (e.g. "Acessar Wiki", "Ver Servidores")
- Active navigation item indicator (left border or underline)
- Category card icon accents (icon fill only, not background)
- Hero search button
- Link hover state in body text

**Accent is NOT used for:** card backgrounds, section backgrounds, all interactive elements indiscriminately, decorative borders.

**Tribal texture note:** A subtle repeating texture overlay (`opacity: 0.03`) can be applied to `--background` via a CSS `::before` pseudo-element using a dark noise/grain SVG pattern. This is optional and must not affect text contrast ratios.

## Layout Contract

### Topbar (56px height, full width)
- Left: Logo (Cinzel 20px, gold accent) + site name "SoulmaskBR"
- Center: Search input (shadcn `command` trigger or `input` with search icon) — non-functional in Phase 1, input renders but does not query
- Right: Empty in Phase 1 (auth link placeholder reserved for Phase 5)
- Background: `--card` (`#141414`)
- Bottom border: 1px `--border`

### Sidebar (240px desktop, full-width Sheet on mobile)
- Trigger: hamburger icon button in topbar (mobile only, lucide `Menu` icon)
- Desktop: static, always visible, `position: sticky, top: 0, height: 100vh`
- Mobile: shadcn `Sheet` component, slides from left
- Content: category navigation links (Wiki, Servidores, Guias, Patch Notes) — links render but point to empty routes in Phase 1
- Active item: left border 2px gold accent, text color `--primary`
- Background: `--card`
- Right border (desktop): 1px `--border`

### Main content area
- `flex-1`, `min-width: 0`
- Max content width: 1280px, centered, horizontal padding: 24px

### Homepage layout (top to bottom)
1. **Hero Banner** — full viewport width, height 480px desktop / 320px mobile. Game art background image (CSS `object-fit: cover`, centered). Overlay: radial gradient `rgba(10,10,10,0.55)` center to edges. Contains: site display title (Cinzel 40px gold) + tagline (Inter 16px warm white) + search input (centered, max-width 560px).
2. **Category Cards row** — 4 cards in a responsive grid (4-col desktop, 2-col tablet, 1-col mobile). Cards: shadcn `card`, dark background, category icon (lucide), category name (Cinzel 24px), short description (Inter 16px muted). Cards link to future routes.
3. **Featured sections row** — 2 columns (desktop): "Últimas Notícias" placeholder + "Servidores em Destaque" placeholder. Renders empty state copy (see Copywriting Contract). This section is a layout placeholder; content comes in Phase 2 and Phase 4.
4. **Footer** — minimal: copyright text (Inter 14px muted) + "Contato" link. Background: `--card`. Top border: 1px `--border`. Padding: 24px vertical.

## Interaction Contract

### Search input (topbar and hero)
- Phase 1: renders as a standard `input` element (shadcn `input` component)
- Placeholder text: "Buscar itens, máscaras, guias..."
- On focus: border color transitions to `--primary` (gold), transition duration 150ms ease
- On submit / Enter: no-op in Phase 1 (search index built in Phase 2)
- Icon: lucide `Search` icon (left-aligned inside input)

### Navigation links
- Default: Inter 14px, `--muted-foreground`
- Hover: `--foreground` (warm white), transition 100ms
- Active: `--primary` (gold) + 2px left border (sidebar) or bottom underline (topbar if applicable)
- No animation beyond color transition

### Category cards
- Default: `--card` background, `--border` border
- Hover: border color `--primary` (gold), `box-shadow: 0 0 0 1px var(--primary)`, transition 150ms ease
- Cursor: pointer
- No scale transform (performance on mobile)

### Mobile sidebar (Sheet)
- Opens on hamburger button tap
- Closes on: backdrop tap, route navigation, Escape key
- Animation: shadcn Sheet default (slide from left, 200ms)

### Transitions policy
- All color transitions: 150ms ease
- No layout animations in Phase 1 (reserved for later polish)
- Reduced motion: respect `prefers-reduced-motion` — disable all transitions when set

## Accessibility Contract

- All interactive elements: minimum 44px touch target
- Color contrast: all text on background must meet WCAG AA (4.5:1 for body, 3:1 for large text)
  - `--foreground` (`#f5f0e8`) on `--background` (`#0a0a0a`) = ~19:1 — passes
  - `--primary` (`#c9973a`) on `--background` (`#0a0a0a`) = ~7:1 — passes for large text; use white text on gold buttons
  - Button text on `--primary` background: use `#0a0a0a` (black) — ~7:1 — passes
- `aria-label` on icon-only buttons (hamburger menu: `aria-label="Abrir menu"`)
- Search input: `aria-label="Buscar conteúdo"` or `<label>` association
- Sidebar nav links: `aria-current="page"` on active route
- Hero background image: `role="img"` with `aria-label="Arte do Soulmask"` on the container, OR pure CSS background (preferred — decorative)
