    This is the core client-side filtering/sorting/pagination component per Pitfall 1 (avoids searchParams in Server Component).

    ```
    'use client'
    ```

    Props: `items: ContentItem[]`, `subcategories: string[]`, `category: string`

    State management (all via `useSearchParams` for shareable URLs per UI-SPEC):
    - `view`: 'grid' | 'table' (from `?view=` query param, default 'grid') — per D-04
    - `subcategory`: string (from `?sub=` param, default 'Todos') — per D-05
    - `sort`: string (from `?sort=` param, default 'nome-az') — per D-05
    - `page`: number (from `?page=` param, default 1) — per D-06

    Filtering pipeline:
    1. Filter by `published: true` (only show published items to visitors)
    2. Filter by subcategory (if not 'Todos')
    3. Sort by selected option: "Nome (A-Z)", "Nome (Z-A)", "Categoria", "Tier"
    4. Paginate: grid view = 24 items/page, table view = 50 items/page (per UI-SPEC)

    Render structure:
    ```
    <FilterBar /> (imported from separate component)
    <p className="text-sm text-muted-foreground mt-2">{N} resultados encontrados</p>
    {view === 'grid' ? <GridView /> : <TableView />}
    <Pagination /> (shadcn pagination, centered, 48px top margin)
    ```

    Grid view: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4` — renders ItemCard for each item.
    Table view: shadcn `table` with columns per UI-SPEC (Image 40px | Nome | Categoria | Tier | Versao for items; Image | Nome | Skills principais | Tier | Dificuldade for masks). Row hover: `bg-muted`. On mobile hide last 1-2 columns per UI-SPEC.

    Empty state: when no published items exist, show "Nenhum conteudo publicado ainda" heading + "Este conteudo esta sendo traduzido e revisado. Volte em breve." body (per UI-SPEC copywriting).

    Pagination: use shadcn `pagination` component. Show up to 7 page numbers with ellipsis. Current page: `bg-primary text-primary-foreground`. Disabled prev/next: `opacity-40 cursor-not-allowed`. Use `aria-label="Paginacao"` and `aria-current="page"` per UI-SPEC accessibility.
