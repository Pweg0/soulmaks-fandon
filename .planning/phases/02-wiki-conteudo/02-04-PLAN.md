    - State: `results: PagefindResult[]`, `isLoading: boolean`.

    **Dropdown UI** per UI-SPEC:
    - Floating panel: `absolute top-full left-0 w-full` (or maxWidth if provided), `max-h-[400px] overflow-y-auto`.
    - Background: `bg-card border border-border rounded-lg shadow-[0_8px_24px_rgba(0,0,0,0.5)]`.
    - Each result item: 44px min-height, `px-4 py-2`. Title in Inter 16px, category label in Inter 14px `text-muted-foreground`. Hover: `bg-muted`.
    - Matched term highlight: `background: rgba(237,160,29,0.2)` and `text-primary` — inject via `dangerouslySetInnerHTML` on Pagefind's excerpt which already wraps matches in `<mark>`.
    - Style the `<mark>` tag: `mark { background: rgba(237,160,29,0.2); color: hsl(var(--primary)); }` in globals.css.
    - No results: "Nenhum resultado encontrado" centered, Inter 16px `text-muted-foreground`. Below: "Tente outros termos ou navegue pelas categorias." per UI-SPEC.
    - Loading state: 2 skeleton rows (shadcn Skeleton, 44px height each) with `aria-busy="true"`.

    **Accessibility** per UI-SPEC:
    - Container: `role="listbox"`. Each result: `role="option"`.
    - `aria-activedescendant` tracks focused result.
    - `aria-live="polite"` for result count announcements.
    - Keyboard: ArrowUp/ArrowDown navigate results, Enter navigates to page, Escape closes.

    - Add click-outside handler to close dropdown.
