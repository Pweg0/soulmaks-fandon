# Phase 2 — UI Design Contract

> Visual and interaction contract for wiki content pages. Generated by gsd-ui-researcher.
> This phase INHERITS all tokens from Phase 1 (01-UI-SPEC.md). Only new patterns are defined here.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (already initialized in Phase 1) |
| Preset | inherited — run `npx shadcn@latest add` for new components only |
| Component library | Radix UI (via shadcn) — inherited |
| Icon library | lucide-react — inherited |
| Font | Cinzel (headings) + Inter (body) — inherited from Phase 1 |

**New shadcn components required for Phase 2:**
`accordion`, `table`, `tabs`, `select`, `skeleton`, `tooltip`, `breadcrumb`, `pagination`

**Add command:**
```bash
npx shadcn@latest add accordion table tabs select skeleton tooltip breadcrumb pagination
```

**Search library (Claude's Discretion — D-10):** Pagefind
- Rationale: static-site index, zero runtime cost, no server round-trip, works with Next.js static export, best fit for 75+ MDX files. Fuse.js is client-only and slower at scale; Pagefind pre-builds a search index at build time.
- Integration: `pagefind` npm package, index built via post-build script, results fetched client-side via `window.pagefind`.

Inherited from Phase 1. No additions for Phase 2.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tag/badge padding, icon gaps |
| sm | 8px | Inline spacing, compact button padding |

## Color

Inherited from Phase 1. Phase 2 adds two semantic surface uses and one new CSS variable.

| Role | CSS Variable | Hex Reference | Usage |
|------|-------------|---------------|-------|
| Dominant (60%) | `--background` | `#0f0f0f` | Page background |
| Secondary (30%) | `--card` | `#171717` | Item cards, filter bar, sidebar, stat block background |
| Accent (10%) | `--primary` | `#eda01d` | See reserved list below |
| Tier badge surface | `--secondary` | `hsl(25 50% 22%)` dark brown | Tier/difficulty badge background only |
| Muted surface | `--muted` | `#212121` | Skeleton loaders, empty table rows, collapsible section backgrounds |
| Tier A border | `--tier-a` | `hsl(200 60% 35%)` | A-tier mask badge border only |
| Destructive | `--destructive` | red | Not used in Phase 2 |

**Accent (`--primary`) reserved for — Phase 2 additions:**
- Active filter pill/tag indicator (left border or bottom underline)
- Grid/Table view toggle active indicator
- Search result highlight (matched term background: `rgba(237,160,29,0.2)`)
- Breadcrumb current page text
- Patch note version badge border
- Item page section divider lines (subtle horizontal rule: `1px solid rgba(237,160,29,0.25)`)

**Accent is NOT used for:** row hover backgrounds, all badge backgrounds, pagination button backgrounds.

**New CSS variable — `--tier-a`:**
```css
--tier-a: hsl(200 60% 35%);
```
Add to `:root` in `globals.css`. Used exclusively for A-tier mask badge border color.

**Tier badge semantics:**
- S/Legendary: `--primary` gold border, `--secondary` background
- A: `--tier-a` (steel blue) border, `--secondary` background
- B and below: `--border` (gray) border, `--muted` background

## Page Layout Contracts

### Category Listing Page (`/wiki/[category]`)

Layout: full-width within main content area (max 1280px, 24px horizontal padding).

```
[ Breadcrumb ]
[ Category Hero — Cinzel Display title + subtitle ]
[ Filter Bar — sticky, below topbar ]
  [ Subcategory tabs | Sort select | View toggle (Grid/Table) | Result count ]
[ Content Zone ]
  — Grid view: 3-col desktop / 2-col tablet / 1-col mobile
  — Table view: full-width responsive table
[ Pagination — centered, numeric ]
```

**Filter Bar:**
- Position: `sticky`, `top: 56px` (below topbar), `z-index: 10`
- Background: `--card`, bottom border `1px --border`
- Height: 56px
- Content left-to-right: subcategory `tabs` (scrollable on mobile) | spacer | sort `select` | grid/table `button` toggle group
- Result count: Inter 14px muted-foreground, immediately below filter bar (not inside it)

**Grid view — item card:**
- Component: shadcn `card` with custom content
- Dimensions: auto height, min-height 120px
- Layout (top to bottom): category badge (top-left) | item image (64x64px, centered, object-contain) | item name (Inter 16px bold — weight 700) | tier badge (if applicable)
- Hover: border color `--primary`, `box-shadow: 0 0 0 1px var(--primary)`, 150ms ease — same as Phase 1 category cards
- Click: navigates to item page

**Table view:**
- Component: shadcn `table`
- Columns (items): Image (40px) | Nome | Categoria | Tier | Versão
- Columns (masks): Image (40px) | Nome | Skills principais | Tier | Dificuldade
- Row hover: background `--muted` (no border change in table mode)
- Sortable column headers: lucide `ArrowUpDown` icon (14px), cursor pointer
- Responsive: on mobile, hide "Versão" / "Dificuldade" columns; keep Nome and Tier

**Pagination:**
- Component: shadcn `pagination`
- Style: numeric, show up to 7 page numbers with ellipsis
- Items per page: 24 (grid), 50 (table)
- Position: centered, 48px top margin

### Item Detail Page (`/wiki/itens/[slug]`)

Layout: two-zone on desktop, single-column on mobile.

```
[ Breadcrumb ]                                        full width
[ Item Hero Card — "card expansivo" ]                 full width
  [ Image (left, 160x160) | Name + Category + Tier badge | Description ]
[ Content Sections — below hero ]                     full width
  [ Stats Block ]          accordion (open by default)
  [ Crafting Recipe ]      accordion (open by default)
  [ Localização ]          accordion (open by default)
  [ Itens Relacionados ]   accordion (collapsed by default)
[ MDX Body ]               full width, below accordions
```

**Item Hero Card ("card expansivo"):**
- Component: shadcn `card`, full-width
- Background: `--card`
- Border: `1px --border`, with `box-shadow: 0 0 0 1px rgba(237,160,29,0.15)` (subtle gold glow)
- Left zone: item image 160x160px, `object-contain`, background `--muted`, border-radius `--radius-md`
- Right zone: item name (Cinzel 24px bold), category badge, tier badge, description (Inter 16px, 1.5 line-height)
- Mobile: image above text (stacks vertically), image 96x96px

**Stats Block:**
- Component: shadcn `accordion` (open by default)
- Heading: "Estatísticas" (Cinzel 24px)
- Layout inside: CSS grid 2-col (label | value), Inter 14px labels, Inter 16px bold (weight 700) stat values — Body bold role, not a new type scale entry
- Section divider: `1px solid rgba(237,160,29,0.25)` between stat groups

**Crafting Recipe:**
- Component: shadcn `accordion` (open by default)
- Heading: "Receita de Crafting" (Cinzel 24px)
- Layout: horizontal scrollable ingredient list — each ingredient is a mini card (40x40px image + name + quantity)
- Ingredient card hover: border `--primary`, 150ms

**Localização:**
- Component: shadcn `accordion` (open by default)
- Heading: "Onde Encontrar" (Cinzel 24px)
- Layout: bulleted list (Inter 16px), location names as text (map integration deferred to v2)

**Itens Relacionados:**
- Component: shadcn `accordion` (collapsed by default)
- Heading: "Itens Relacionados" (Cinzel 24px)
- Layout: horizontal scrollable row of item mini-cards (same style as ingredient cards)

**MDX Body:**
- Prose styles: `max-width: none`, Inter 16px, 1.5 line-height
- `h2` within MDX: Cinzel 24px bold (mapped to Heading role)
- `h3` within MDX: Inter 16px bold (weight 700) — distinct from body through weight alone, no new scale entry
- `a` within MDX: `--primary` color, underline on hover, 150ms
- `code` inline: `--muted` background, Inter 14px, `border-radius: 4px`, 4px padding horizontal
- `blockquote`: left border 2px `--primary`, `--muted` background, 16px padding

### Mask Detail Page (`/wiki/mascaras/[slug]`)

Layout: same single-column structure as item page but with mask-specific sections.

```
[ Breadcrumb ]                                        full width
[ Mask Hero Card ]                                    full width
  [ Mask image (160x160) | Name + Tier badge | Description ]
[ Content Sections ]
  [ Habilidades (Skills) ]    accordion (open by default)
  [ Builds Recomendados ]     accordion (open by default)
  [ Modo Mimetismo ]          accordion (open by default, if applicable)
  [ Nós da Máscara ]          accordion (collapsed by default)
[ MDX Body ]                                          full width
```

**Mask Hero Card:**
- Same structure as Item Hero Card with one addition: "Dificuldade" badge alongside Tier badge
- Dificuldade values: "Iniciante" | "Intermediário" | "Avançado" — badge colors map to tier badge semantic colors

**Habilidades (Skills) Section:**
- Component: shadcn `accordion` (open)
- Layout: skill list — each skill is a row: skill icon placeholder (32x32px `--muted` square) | skill name (Inter 16px bold) | skill description (Inter 16px, muted-foreground)
- Passive vs Active: `badge` ("Passivo" | "Ativo") with `--muted` background, `--border` border

**Builds Recomendados:**
- Component: shadcn `accordion` (open)
- Layout: shadcn `tabs` — each tab is a build name (e.g. "Combate", "Suporte", "Exploração")
- Tab content: bullet list of recommended skill nodes + playstyle description (Inter 16px)

**Modo Mimetismo:**
- Component: shadcn `accordion` (open if mask has mimicry; omit section entirely if not)
- Layout: two sub-sections ("Efeito Passivo" | "Efeito Ativo") — each with Inter 16px description

**Nós da Máscara:**
- Component: shadcn `accordion` (collapsed by default — content is dense)
- Layout: text list of node names and descriptions (Inter 14px label + Inter 16px description per node)

### Patch Notes Page (`/wiki/patch-notes`)

Layout: single column, chronological list (most recent first — D-09).

```
[ Breadcrumb ]
[ Page Title: "Patch Notes" (Cinzel 40px Display) ]
[ Patch list — most recent first ]
  [ Patch entry ]
    [ Version badge + Date (Inter 14px muted) ]
    [ Patch title (Cinzel 24px) ]
    [ Summary excerpt (Inter 16px, 3 lines max) ]
    [ "Ler mais" link ]
  ...
[ Pagination — numeric, 10 patches per page ]
```

**Patch Entry:**
- Component: shadcn `card`, horizontal layout
- Left accent: 3px left border `--primary` (gold stripe — visual marker for chronology)
- Version badge: `badge` component, background `--muted`, border `1px --primary`, text `--primary`, Inter 14px
- Date: Inter 14px `--muted-foreground`
- Title: Cinzel 24px `--foreground`
- Excerpt: Inter 16px `--muted-foreground`, `-webkit-line-clamp: 3`
- CTA: "Ler mais" — Inter 14px `--primary`, no underline by default, underline on hover

**Individual Patch Note Page (`/wiki/patch-notes/[slug]`):**
- Layout: centered single column, max-width 720px (optimal reading width for long text)
- Header: version badge + date + title (same styles as list entry)
- Body: MDX prose (same MDX styles as item pages)
- Navigation: "Patch anterior" / "Próximo patch" links at bottom (Inter 14px)

### Search Results

Search is not a dedicated page (D-11). Results appear inline in topbar and hero banner.

**Topbar search dropdown:**
- Trigger: typing in topbar `input`
- Overlay: floating panel below topbar input, full width of input, max-height 400px, `overflow-y: auto`
- Background: `--card`, border `1px --border`, border-radius `--radius-lg`, `box-shadow: 0 8px 24px rgba(0,0,0,0.5)`
- Result item: Inter 16px title + Inter 14px muted category label, 44px min-height, hover `--muted` background
- Matched term highlight: `background: rgba(237,160,29,0.2)`, `color: --primary`
- No results: "Nenhum resultado encontrado" (Inter 16px muted, centered)
- Keyboard: Arrow keys navigate results; Enter navigates to page; Escape closes
- Loading state: skeleton rows (shadcn `skeleton`, 2 rows, 44px height each)

**Hero search behavior:**
- Identical visual behavior to topbar dropdown but anchored below the hero search input
- Panel max-width: 560px (matches hero input width)

## Interaction Contract

### Accordion (item/mask content sections)
- Default open sections: Stats, Crafting, Localização, Skills, Builds, Mimetismo
- Default collapsed: Itens Relacionados, Nós da Máscara
- Transition: shadcn accordion default (height animate, 200ms ease-out)
- Icon: lucide `ChevronDown`, rotates 180deg when open, 200ms
- Reduced motion: skip height animation, show/hide instantly

### Grid / Table toggle
- Component: two `button` variants side by side (icon only — lucide `LayoutGrid` / `Table2`)
- Active state: background `--primary`, icon color `--primary-foreground` (near-black)
- Inactive state: background `--muted`, icon color `--muted-foreground`
- Toggle persists in URL query param `?view=grid` or `?view=table` (for shareable URLs)
- Transition: 100ms background color change
- Tooltip: shadcn `tooltip` on each button — `"Visualização em grade"` (grid) / `"Visualização em tabela"` (table); delay 500ms; position above button

### Filter tabs (subcategory)
- Component: shadcn `tabs` (pill style, not underline)
- Active: background `--primary`, text `--primary-foreground`
- Inactive: background transparent, text `--muted-foreground`, hover text `--foreground`
- Mobile: `overflow-x: auto`, `white-space: nowrap`, hide scrollbar visually

### Sort select
- Component: shadcn `select`
- Options: "Nome (A-Z)" | "Nome (Z-A)" | "Categoria" | "Tier"
- Default: "Nome (A-Z)"
- Width: 160px on desktop, full-width on mobile

### Skeleton loading states
- Category listing: 6 skeleton cards (grid) or 5 skeleton rows (table)
- Item/mask page: skeleton hero card (full width, 160px height) + 3 skeleton accordion rows
- Duration: 1.5s shimmer animation (`animate-pulse` from Tailwind)
- Color: `--muted` base with `--border` highlight

### Breadcrumb
- Component: shadcn `breadcrumb`
- Position: top of every content page, 24px top margin, 0px bottom margin
- Separator: lucide `ChevronRight` (12px)
- Items: "Início" > "Wiki" > [Category] > [Page title]
- Current page: `--primary` color (gold), not a link
- Previous items: `--muted-foreground`, link hover `--foreground`, 100ms

### Pagination
- Component: shadcn `pagination`
- Show: first, prev, up to 5 numbered pages, ellipsis, next, last
- Current page: background `--primary`, text `--primary-foreground`
- Inactive: background transparent, border `1px --border`
- Hover: background `--muted`
- Disabled (prev on page 1, next on last page): opacity 0.4, cursor not-allowed

### Transitions policy (inherits Phase 1)
- All color transitions: 150ms ease
- Accordion height: 200ms ease-out
- No layout animations
- Reduced motion: disable all animations via `prefers-reduced-motion`

## Accessibility Contract

Inherits Phase 1. Phase 2 additions:

- Breadcrumb: `<nav aria-label="Navegação de caminho">` wrapping `<ol>` list; current page `aria-current="page"`
- Accordion: uses Radix UI `Accordion` primitives — `aria-expanded`, `aria-controls`, `id` linkage handled automatically
- Table: `<caption>` element with category + filter description for screen readers; `<th scope="col">` on all headers
- Filter tabs: `role="tablist"`, `aria-selected` on active tab; each panel `role="tabpanel"` with `aria-labelledby`
- Grid/Table toggle: `aria-label="Visualização em grade"` / `aria-label="Visualização em tabela"`; active button `aria-pressed="true"`
- Search dropdown: `role="listbox"`, each result `role="option"`, `aria-activedescendant` tracks focused result; container `aria-live="polite"` for result count announcements
- Skeleton loaders: `aria-busy="true"` on container while loading; `aria-hidden="true"` on skeleton elements
- Images: item/mask images `alt="{item name}"` — never empty for content images; decorative images `alt=""`
- Pagination: `<nav aria-label="Paginação">`, current page button `aria-current="page"`, disabled buttons `aria-disabled="true"`
