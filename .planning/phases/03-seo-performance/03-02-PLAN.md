    **1. Create `src/lib/jsonld.ts`** — Pure helper functions returning plain objects:

    ```typescript
    const BASE_URL = process.env.NEXT_PUBLIC_SITE_URL ?? 'https://soulmaskbr.com'
    ```

    Export functions:

    - `videoGameSchema()` — Returns `{ '@context': 'https://schema.org', '@type': 'VideoGame', name: 'Soulmask', description: 'Survival game com habilidades baseadas em mascaras por Qooland Games', genre: ['Survival', 'Open World', 'Action RPG'], gamePlatform: ['PC', 'Steam'], url: BASE_URL, inLanguage: 'pt-BR', publisher: { '@type': 'Organization', name: 'Qooland Games' } }`

    - `breadcrumbSchema(items: Array<{ name: string; url: string }>)` — Returns `{ '@context': 'https://schema.org', '@type': 'BreadcrumbList', itemListElement: items.map((item, i) => ({ '@type': 'ListItem', position: i + 1, name: item.name, item: item.url })) }`

    - `articleSchema(title: string, description: string, url: string, datePublished?: string)` — Returns `{ '@context': 'https://schema.org', '@type': 'Article', headline: title, description, url, inLanguage: 'pt-BR', ...(datePublished && { datePublished }) }`

    - `websiteSchema()` — Returns `{ '@context': 'https://schema.org', '@type': 'WebSite', name: 'SoulmaskBR', url: BASE_URL, description: 'O guia completo de Soulmask em portugues', inLanguage: 'pt-BR' }`

    - `webPageSchema(name: string, url: string)` — Returns `{ '@context': 'https://schema.org', '@type': 'WebPage', name, url, inLanguage: 'pt-BR' }` (per D-04: simple schema for category listing pages)

    All functions are pure, no side effects, server-safe. No external dependencies.
