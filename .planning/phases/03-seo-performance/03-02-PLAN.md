    **1. Create `src/lib/jsonld.ts`** — Pure helper functions returning plain objects:

    ```typescript
    const BASE_URL = process.env.NEXT_PUBLIC_SITE_URL ?? 'https://soulmaskbr.com'
    ```

    Export functions:

    - `videoGameSchema()` — Returns `{ '@context': 'https://schema.org', '@type': 'VideoGame', name: 'Soulmask', description: 'Survival game com habilidades baseadas em mascaras por Qooland Games', genre: ['Survival', 'Open World', 'Action RPG'], gamePlatform: ['PC', 'Steam'], url: BASE_URL, inLanguage: 'pt-BR', publisher: { '@type': 'Organization', name: 'Qooland Games' } }`

    - `breadcrumbSchema(items: Array<{ name: string; url: string }>)` — Returns `{ '@context': 'https://schema.org', '@type': 'BreadcrumbList', itemListElement: items.map((item, i) => ({ '@type': 'ListItem', position: i + 1, name: item.name, item: item.url })) }`

    - `articleSchema(title: string, description: string, url: string, datePublished?: string)` — Returns `{ '@context': 'https://schema.org', '@type': 'Article', headline: title, description, url, inLanguage: 'pt-BR', ...(datePublished && { datePublished }) }`

    - `websiteSchema()` — Returns `{ '@context': 'https://schema.org', '@type': 'WebSite', name: 'SoulmaskBR', url: BASE_URL, description: 'O guia completo de Soulmask em portugues', inLanguage: 'pt-BR' }`

    All functions are pure, no side effects, server-safe. No external dependencies.

    **2. Modify `src/app/page.tsx`** — Add VideoGame + WebSite JSON-LD:
    - Import `videoGameSchema`, `websiteSchema` from '@/lib/jsonld'
    - Add before the closing `</>`:
      ```tsx
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{ __html: JSON.stringify(videoGameSchema()) }}
      />
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{ __html: JSON.stringify(websiteSchema()) }}
      />
      ```
    - This is a Server Component so dangerouslySetInnerHTML is safe (no user input)

    **3. Modify `src/app/wiki/[category]/[slug]/page.tsx`** — Add BreadcrumbList JSON-LD:
    - Import `breadcrumbSchema`, `articleSchema` from '@/lib/jsonld'
    - Define `const BASE_URL = process.env.NEXT_PUBLIC_SITE_URL ?? 'https://soulmaskbr.com'`
    - After the existing breadcrumb HTML component, add:
      ```tsx
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{ __html: JSON.stringify(breadcrumbSchema([
          { name: 'Inicio', url: BASE_URL },
          { name: 'Wiki', url: `${BASE_URL}/wiki` },
          { name: categoryLabel, url: `${BASE_URL}/wiki/${category}` },
          { name: frontmatter.title, url: `${BASE_URL}/wiki/${category}/${slug}` },
        ])) }}
      />
      ```
    - For guide pages (`category === 'guias'`), also add Article JSON-LD (per research: default to Article, not HowTo, since MDX content may not have machine-readable steps):
      ```tsx
      {category === 'guias' && (
        <script
          type="application/ld+json"
          dangerouslySetInnerHTML={{ __html: JSON.stringify(articleSchema(
            frontmatter.title,
            `${frontmatter.title} — guia completo para jogadores de Soulmask em portugues.`,
            `${BASE_URL}/wiki/${category}/${slug}`
          )) }}
        />
      )}
      ```
    - Do NOT add HowTo schema to item/mask pages (per research pitfall #5)

    **4. Modify `src/app/wiki/patch-notes/[slug]/page.tsx`** — Add BreadcrumbList JSON-LD:
    - Import `breadcrumbSchema` from '@/lib/jsonld'
    - Define `const BASE_URL = process.env.NEXT_PUBLIC_SITE_URL ?? 'https://soulmaskbr.com'`
    - Add breadcrumb JSON-LD matching the HTML breadcrumb structure:
      ```tsx
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{ __html: JSON.stringify(breadcrumbSchema([
          { name: 'Inicio', url: BASE_URL },
          { name: 'Wiki', url: `${BASE_URL}/wiki` },
          { name: 'Patch Notes', url: `${BASE_URL}/wiki/patch-notes` },
          { name: frontmatter.title, url: `${BASE_URL}/wiki/patch-notes/${slug}` },
        ])) }}
      />
      ```

    **ANTI-PATTERNS TO AVOID:**
    - Do NOT apply HowTo schema to non-guide pages (items, masks) — HowTo requires actionable steps (research pitfall #5)
    - Do NOT use a JSON-LD library (schema-dts, react-schemaorg) — plain objects are sufficient (per research Don't Hand-Roll table)
    - Do NOT place JSON-LD in `<head>` via metadata API — inject as `<script>` in component JSX body (Google supports both, but component injection is the standard pattern for App Router Server Components)
