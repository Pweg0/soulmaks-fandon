# Bifold Window

}}
**Bifold Window** is a building item in *Soulmask*.
## Acquisition
It is unlocked via the Knowledge and Technology tree under Bronze Pit Bonfire: Advanced Building.
## Usage
 can only be placed within the Window Wall variants of the Thatch Wall, Wooden Wall, Stone Wall, or Blackstone Wall building pieces.

Once in place, it can be open and closed.

It can only be Dismantled, not Retrieved.
