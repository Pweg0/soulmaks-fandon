# Double Chair

<br/>






}}
**Double Chair** é uma construção em *Soulmask*.

## Obtenção
It Pode ser fabricado in the Building Workshop.

## Uso
Can be placed, increasing the Comfort Level by 50. Interacting with it allows you to rest on it, slowly regenerating Morale. Idle tribesmen will always sit on it. Has 2 sitting places.
