# Wooden Chest

}}
**Wooden Chest** is a storage item in *Soulmask*.

It has 66 (6x11) slots.

It can be directly upgraded to a Metal Chest.

Note:  is not an upgrade of Small Wooden Chest, as it takes up significantly more space.
