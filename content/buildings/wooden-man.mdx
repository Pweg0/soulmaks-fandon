# Wooden Man

}}
**Wooden Man** is a building item in *Soulmask*.
## Obtenção
It is unlocked via the Knowledge and Technology tree under Bronze Pit Bonfire: Advanced Building.
## Uso
Once placed,  can be used to display armor. It works like a tribesman regarding inventory, features the Quick Exchange options and will display equipped items. It will only display the male version of the armor.
