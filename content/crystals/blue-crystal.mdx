# Blue Crystal

<br/>
}}
**Blue Crystal** is an item in *Soulmask*.

## Acquisition
It can be found as a loot by killing Pyramid bosses from Temple Guardians in any difficulty.
## Usage
*Repairing mask nodes
*Crafting masks and items in the Mysterious Stone Table
*Activating Mysterious Portals
