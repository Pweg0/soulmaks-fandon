# Fruit Wine

<br/><br/>







}}
**Fruit Wine** is a food in *Soulmask*.
## Description
A refreshing beverage made using a brewing stand with tree bark, yeast, and a cup. Optional ingredients include wild fruit, banana, pineapple, and papaya. It is used in various crafting recipes, including Almighty Vajra Ape Token.

## Acquisition
Can be obtained through the following:
*Brewing Stand: (Required: Tree Bark x5 + Yeast x2 + Cup x1) (Optional: Wild Fruit x5 + Banana x5 + Pineapple x5 + Papaya x5)
