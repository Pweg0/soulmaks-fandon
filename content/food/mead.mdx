# Mead

}}
**Mead** is a food in *Soulmask*.
## Description
A brewed beverage made using a brewing stand with honey, tree bark, yeast, and a cup, used in various crafting recipes.

## Acquisition
Can be obtained through the following:

* Brewing Stand: (Honey x5 + Tree Bark x10 + Yeast x4 + Cup x1) 

*
## Usage
Mead is used in various crafting recipes, including:
*Berserk Vajra Ape Token
*Vajra Ape of Doom Token
