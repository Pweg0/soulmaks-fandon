**Ancient Enhance Table** is a building in *Soulmask*.

## Description
An ancient technology only obtainable by reading texts about long-forgotten armor enhancing techniques.
## Acquisition
The  node in the Knowledge and Technology tree (Steel Pit Bonfire era) is not accessible until reading the Ancient Texts item, which can be looted after defeating the Central Core in the Frost Canyon Holy Ruins.

Once the knowledge is unlocked, it can be crafted at a Building Workshop using the following materials:
*20x Mysterious Alloy 
*20x Mysterious Crystal 
*20x Mysterious Magnet 
*100x Blackstone Brick 
*30x Precision Part 
*30x Glass 
Rare material Locations:
*Mysterious Alloy is only found in Holy Ruins or Ancient Dungeons
*Mysterious Magnet is only found in the Giant Crater (desert) Holy Ruins
*Mysterious Crystal is only found in the Frost Canyon Holy Ruins
## Usage
's primary use is to upgrade Steel armor pieces.
