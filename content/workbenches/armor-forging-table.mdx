**Armor Forging Table** is a building in *Soulmask*.

## Description
At this table you can craft any armor higher than linen aswell as rings and necklaces.

For higher tiers you need to add the modifications Armor Forging Table Part 1, Armor Forging Table Part 2 and Armor Forging Table Part 3
